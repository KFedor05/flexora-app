# План проекта: Flexora — трекер ежедневных рутин со стриками

## 🎯 Концепция

Кросс-платформенное десктоп-приложение для отслеживания ежедневных рутин с фокусом на:

- **Шаблоны по дням недели** — у каждого дня недели свой набор задач
- **Стрики** — счётчик подряд идущих выполнений у каждой задачи (как в TikTok / Duolingo / Snapchat)
- **Календарь** с цветовой картой выполнения (зелёный / жёлтый / красный)
- **"Идеальный день"** — мета-стрик, когда выполнены все задачи дня
- **"Не смог по причине"** — кнопка-пропуск, сохраняющая стрик
- **Ретроактивное редактирование** — можно вернуться в прошлый день и проставить отметки
- **Счётчики** — отдельный тип задач с накоплением (отжимания, вода, и т.д.)

Опенсорс, под Windows / macOS / Linux, с автоматической сборкой релизов через GitHub Actions. Цель — портфельный проект, который при этом будет реально полезен людям.

## 🧩 Структура данных (schema)

Главная сущность — **привычка** (habit), у которой есть свои правила повторения. День — это автоматически сгенерированный срез привычек, активных в эту дату.

```
{
  "habits": [
    {
      "id": "<uuid>",
      "title": "Зал",
      "sectionId": "morning",
      "type": "checkbox" | "counter",        // обычная или счётчик
      "counter": {                            // только если type === "counter"
        "target": 2,                          // цель — любое число
        "unit": "л",                          // подпись единицы измерения
        "steps": [0.2, 0.4]                   // от 1 до 5 шагов, каждый → пара кнопок +X/-X
      },
      "frequency": {
        "type": "byDays" | "interval",
        "days": ["mon","tue","wed","thu","fri"], // если type=byDays
        "preset": "all" | "weekdays" | "weekends" | "custom",
        "intervalDays": 3                        // если type=interval (раз в N дней)
      },
      "startDate": "2026-06-02",              // когда привычка начинается
      "endDate": null,                         // дата окончания (null = бессрочно)
      "goalPreset": "indefinite" | "7d" | "30d" | "100d" | "365d" | "custom",
      "order": 5,                              // позиция в секции
      "archived": false,                       // удаление (ошибка / не нужно)
      "completed": false,                      // завершена пользователем (успешно довёл до конца)
      "completedAt": null,                     // дата завершения
      "createdAt": "2026-06-02T08:00:00Z"
    }
  ],
  "sections": [
    { "id": "morning", "name": "Утро",   "order": 0, "isDefault": true },
    { "id": "day",     "name": "День",    "order": 1, "isDefault": true },
    { "id": "evening", "name": "Вечер",   "order": 2, "isDefault": true },
    { "id": "other",   "name": "Другое",  "order": 3, "isDefault": true },
    { "id": "<uuid>",  "name": "Кастомная","order": 4, "isDefault": false }
  ],
  "days": {
    "2026-06-02": {
      "entries": [
        {
          "habitId": "<uuid>",
```

### Правило: "должна ли привычка появиться в день D?"

Привычка появляется в день D, если выполнены **все** условия:
1. `D >= habit.startDate`
2. `habit.endDate === null` ИЛИ `D <= habit.endDate`
3. `habit.archived === false` (или это исторический день, который её застал)
4. `habit.completed === false` (или это исторический день до `completedAt`)
5. День недели для D подходит по `frequency`:
   - `byDays`: день недели входит в `frequency.days`
   - `interval`: `(D - startDate) % intervalDays === 0`

### Философия и правила редактирования

**Flexora — приложение про серьёзный коммитмент.** В нём нет "лёгких выходов":

- ❌ **Кнопки "Удалить" нет** (ни у привычек, ни у счётчиков)
- 🔒 **Дата старта заблокирована навсегда** после создания — это исторический факт, нельзя редактировать
- ⚠️ **Срок цели редактируется** по правилу `new endDate >= today`:
  - ✅ Можно продлить (30 дней → 100 дней)
  - ✅ Можно сократить, если новая дата в будущем (30 → 7 дней, когда прошло 3 — ОК)
  - ✅ Можно сделать "Бессрочно"
  - ❌ Нельзя сократить так, чтобы endDate оказался в прошлом ("завершение задним числом")
- ✅ **Завершить** — единственный путь "закрыть" привычку. Положительное действие: "успех, цель достигнута"
- ✅ **Остальные поля** (название, секция, частота, шаги счётчика, единица) — редактируются свободно

### Семантика статусов привычек

| Действие | Поле | Семантика | История |
|----------|------|-----------|---------|
| **Завершить** | `completed: true, completedAt: <дата>` | "успех, цель достигнута" | Сохраняется, подсвечивается как достижение |
| **Срок цели истёк** | `endDate < сегодня` | Автоматическое окончание | Сохраняется |
| **Архив** (внутренний) | `archived: true` | Используется только при миграции данных / сбоях. Пользователь не видит этой кнопки | Сохраняется |

Завершённые привычки показываются в отдельной вкладке "Завершённые" / "Достижения" в редакторе.

### UI-правила (мелочи интерфейса)

| Что | Правило |
|-----|---------|
| **Длинные названия задач** | Ограничение при вводе — максимум 60 символов. Никакого обрезания через `...` в UI не нужно |
| **Пустая секция на сегодня** | Если в секции 0 активных задач сегодня — **скрыть секцию полностью** |

| **Счётчик при достижении цели** | Прогресс-бар становится **зелёным** + рядом с прогрессом появляется **огонёк 🔥** |
| **Ввод в числовых полях** | Запрещать ввод не-числовых символов на уровне input. Без тряски/анимации ошибки |

| **Светлая тема** | Делаем сразу в v1.0 — обе темы (Тёмная / Светлая) + Системная (отслеживает ОС) |
| **Drag-and-drop счётчиков** | В правой панели Today счётчики можно переставлять между собой (внутри панели) |
| **Редактор привычек ("По дням")** | Просмотр по дням недели (табы Пн-Вс), без счётчиков, без чекбоксов, без стриков — это режим расписания. Счётчики редактируются через ✏️ на карточке счётчика в правой панели Today |

### Навигация Notion-стиль (иерархия "Назад")

Кнопка **"Назад"** в шапке Today последовательно поднимает по уровням:

```
[Today день] → [Дни месяца] → [Месяцы года] → [Годы]
   today.html       days.html      months.html    years.html
```

При каждом запуске приложения по умолчанию открывается **Today сегодня**.

### Принцип "появления" в иерархии

В списках дней / месяцев / годов запись **появляется только когда она наступила**:
- В `days.html` (дни месяца) — если сегодня 3 июня, видны только 1, 2, 3. Будущие дни **не отображаются**
- В `months.html` (месяцы года) — если сегодня июнь, видны только январь–июнь
- В `years.html` (годы) — отображаются годы, в которых были хоть какие-то данные (минимум — текущий год)

Логика: это **история накопления**, а не календарная сетка. Сетку показывает только `calendar.html` (модалка) — там видно весь месяц целиком включая будущие дни (серым).

**Календарь-модалка** (`calendar.html`) — это **отдельный попап** с цветной сеткой месяца, открывается кнопкой "Календарь" в шапке Today. Не часть иерархии "Назад".

Из каждого уровня клик на запись опускает на уровень глубже:
- Клик на "2026" в years.html → переход в months.html
- Клик на "июнь 2026 г." в months.html → переход в days.html
- Клик на "3" в days.html → переход в today.html (этот день)

## 🖼 Экраны / страницы приложения

### 1. Главный экран (Today)

- Список задач на сегодня, сгруппирован по секциям (Утро / День / Вечер / Другие)
- У каждой задачи **слева**: чекбокс / счётчик, название, стрик-индикатор (🔥 + число)
- У каждой задачи **справа**: ⭐ — **заморозить эту задачу на 1 день** (стрик не растёт, но и не сбрасывается)
- Кнопка **"Отметить особым днём"** сверху справа — заморозка всего дня; день помечается ★ в календаре, считается идеальным
- Перетаскивание задач здесь **запрещено** (только в редакторе)
- Сверху по центру: дата дня (например, "вторник, 2 июня 2026 г.")
- Сверху слева: заголовок "Ежедневник" / Flexora
- Сверху справа кнопки: **Назад** (на уровень выше), **Предыдущий день**, **Следующий день**, **Календарь**, **По дням** (редактор привычек), ➕ новая привычка

### 2. Календарь

- Месячная сетка с цветовой картой:
  - 🟢 Зелёный — идеальный день (все задачи выполнены ИЛИ выполнены + пропущены по причине)
  - 🟡 Жёлтый — частично (есть и выполненные, и пропущенные)
  - 🔴 Красный — ничего не выполнено
  - ⚪ Белый/серый — будущий день
- Клик по дню → переход к этому дню в главном экране для редактирования
- Переключение месяцев ◀ ▶
- Статистика месяца: идеальных дней, средний % выполнения, текущий стрик идеального дня

### 3. Управление привычками (первый запуск + редактирование)

Главный экран настройки привычек. Два режима просмотра:

**Режим А: Плоский список всех привычек** (по умолчанию)
- Привычки сгруппированы по секциям (как на "Сегодня"), но **без чекбоксов и без кнопки заморозки ⭐** — это режим настройки, не выполнения
- Каждый ряд **выше**, чем на "Сегодня" (помещается больше информации)
- В ряду видно: название, частота ("Будни", "Пн/Ср/Пт", "Раз в 3 дня"), тип (чекбокс / счётчик), индикатор стрика 🔥 + число
- **Кнопка ✏️ редактирования** в правом конце ряда (вместо звёздочки) → открывает модалку редактирования
- В модалке редактирования есть кнопки: **Сохранить**, **Отмена**, **✅ Завершить** (успех → в "Достижения"), **🗑 Удалить** (в архив)
- **Drag-and-drop** для переупорядочивания привычек внутри секции и между секциями (хват за весь ряд, без специальной ручки)
- Drag-and-drop секций — можно менять порядок самих секций (хватаешь за заголовок секции)
- Кнопка **➕ Новая привычка** сверху
- Отдельная вкладка / фильтр "Завершённые" и "Архив" — для прошлых достижений и удалённых
- Управление секциями (создать / переименовать / удалить)

**Режим Б: Просмотр по дням недели** (переключатель сверху)
- Табы Пн / Вт / Ср / Чт / Пт / Сб / Вс
- В каждом дне показаны привычки, активные в этот день недели (по их `frequency`)
- Полезно для проверки "что у меня на четверг"
- В этом режиме можно только смотреть и открывать привычку для редактирования (не пересоздавать)

Создание привычки — через модальное окно (см. выше "Модальное окно Новая привычка").

### 4. Панель счётчиков (правая боковая панель на экране "Сегодня")

Счётчики живут **не на отдельной странице**, а в правой панели главного экрана.

- **Положение:** справа, 30–35% ширины окна
- **Поведение:**
  - По умолчанию **свёрнута** в иконку 🔢 (новые пользователи не отвлекаются)
  - При клике раскрывается, состояние запоминается между запусками
  - При ширине окна < 800 px автоматически схлопывается в иконку
- **Содержимое:** карточки счётчиков, активных на сегодня, друг под другом
- **Каждая карточка:** название, прогресс-бар, текущее / цель + единица, стрик 🔥, кнопка ⭐ заморозки, кнопки шагов в сетке 2×2 (+/−)
- **Свой скролл:** независимый от скролла задач
- **Пустое состояние:** "Создай свой первый счётчик" + кнопка ➕
- **Кнопка ➕** внизу панели для добавления нового счётчика

### 5. Настройки

- Тема (system / light / dark)
- Автозапуск при старте ОС
- Сворачивание в трей вместо закрытия
- Уведомления в 00:00 о новом дне (опционально)
- Экспорт / импорт данных
- О программе / лицензия / ссылка на GitHub

## 🔑 Принципы разработки
