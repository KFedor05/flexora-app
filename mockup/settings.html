Внешний вид
Язык
Language of the interface. По умолчанию — English.
Тема
Подстраивается под систему по умолчанию.
Поведение приложения
Запускать при старте системы
Flexora будет автоматически запускаться при входе в Windows.
Сворачивать в трей при закрытии
Окно скрывается в системный трей, а не закрывается. Иконка остаётся доступной возле часов.
Открывать на «Сегодня» при запуске
Если выключено, откроется тот экран, на котором ты закрыл приложение в прошлый раз.
Данные
Экспорт
Скачать все привычки, счётчики и историю в JSON-файл.
Импорт
Восстановить данные из ранее экспортированного JSON-файла. Существующие данные будут заменены.
Открыть папку с данными
~/.config/flexora/
